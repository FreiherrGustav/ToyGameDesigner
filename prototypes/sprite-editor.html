Click a swatch, then click or drag on the "Your edit" canvas to paint. The dashed "+" swatch opens your browser's own color picker (with its eyedropper) for any shade not already here. Every original sprite starts from an automatic extraction of the reference sheet — expect rough edges; that's what this tool is for. A yellow dot in the sidebar marks a sprite you've touched.

New sprite adds a blank 8×8 slot of your own (no reference image, since nothing was extracted for it) — name it, then paint it or import a PNG into it. Click the × on a custom sprite's row to remove it. Import PNG loads any image into whichever sprite is currently selected, stretched to fit the 8×8 grid with no smoothing (nearest-neighbor) — works best starting from already-small or blocky pixel art; anything with soft gradients will just get posterized down to flat 8×8 blocks. Fully transparent pixels (alpha under 50%) import as erased; everything else imports as a flat opaque color, since this engine's own sprite format has no partial transparency.

Frames turn a sprite into a looping animation of up to 8 pixel-edit steps. New frame adds a blank frame right after the one you're on; Duplicate frame does the same but starts from a copy of the current frame (handy for a small tweak between steps); Delete frame removes the current one (disabled once only one is left — every sprite always has at least one frame). Click any thumbnail in the strip to load that frame into "Your edit"; Import PNG and painting both affect only the frame you're currently on. Preview always loops the whole set, live, so you can watch the animation as you build it.

Save JSON downloads everything you've edited or added — frames included — as a single file, a full round-trip format useful for saving progress or handing the whole batch back for integration the way earlier rounds did. Export as JS instead generates ready-to-paste pat(...) calls, in this engine's own house style, for just the sprites that are new or edited; a sprite with more than one frame exports one pat() per frame plus a NAME_FRAMES array tying them together, meant to be copied straight into index.html without anyone needing to hand-derive the pattern/legend form — or the frame array — first.
