# Version K: first five minutes

Screenshots at 1440x900 of the landing screen (variant K), the editor and play mode, in the order a new visitor would meet them. Captured by a script driving the real page with real clicks (`?logo=k`); nothing is mocked. The landing journey screenshots are taken as each scene begins, so exact timing in a live run differs by a second or two.
